# Getting help

- **A question or a problem using slonbase:** read the [documentation](https://slonbase.com/docs/)
  first (the [installation guide](docs/installation.md) and the [deployment guide](docs/deployment.md)
  cover most of it), then open an issue and pick the template that fits.
- **A bug:** open an issue with the version (`slonbase --version`), how you run it, and the steps
  to reproduce. The Health page in the dashboard (Settings, Health) lists what looks wrong.
- **A security problem:** don't open an issue. Follow the [security policy](SECURITY.md).
- **A feature idea:** open an issue describing the problem it would solve.

slonbase is maintained by one person in their own time. There is no paid support and no service
level agreement. Issues are answered as time allows, and security reports within 7 days.
